## 💻 Local Setup & Development

To run the portfolio and resume locally on your computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mikhailemad999/Resume.git
   cd Resume
   ```

2. **Serve locally:**
   ```bash
   # Using Python built-in server:
   python -m http.server 8080
   ```
   Open your browser at `http://localhost:8080` (or `http://localhost:8080/resume.html`).

3. **Re-generate PDF resume (Optional):**
   ```bash
   pip install playwright pymupdf
   playwright install chromium
   python generate_pdf.py
   ```
